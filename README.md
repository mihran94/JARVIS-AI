# JARVIS Blue — Mobile Beta

Static, privacy-first UI demonstration for mobile browsers. The Neural Orb and Tamil chat are **demo only**; no AI backend, microphone, storage, or API keys are connected.

This public repository contains only the standalone web preview, not the private Windows, Android, or server code.

To deploy: GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save. Wait for GitHub Pages to publish the URL shown in Settings → Pages.
